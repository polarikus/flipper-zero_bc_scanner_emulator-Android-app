# История изменений

## 0.1.0 — первая версия (2026-10-11)

Первая публичная версия Android-приложения **BC Scanner** — беспроводного моста между
FlipperZero и целевым устройством (эмуляция COM-сканера).

### Возможности

- **Подключение по BLE.** Соединение с FlipperZero по Bluetooth Low Energy с
  автоматическим выбором последнего использованного устройства и отображением актуального
  статуса (подключено / подключение / не подключено / ошибка).
- **Сканирование кодов.** Распознавание штрихкодов и QR-кодов камерой телефона
  (CameraX + ML Kit). При нескольких кодах в кадре выбирается наиболее уверенно
  распознанный.
- **Автозапуск на Flipper.** При подключении приложение автоматически запускает
  `bc_scanner` на FlipperZero в RPC-режиме.
- **Доставка значения.** Отсканированное значение отправляется на FlipperZero по RPC
  (protobuf) с подтверждением (ack) и ретранслируется в USB COM-порт целевого устройства.
- **Устойчивость к сбоям.** Корректная обработка обрыва связи и ошибок отправки; повтор
  без перезапуска приложения.
- **Локализация.** Язык интерфейса определяется локалью ОС: русский (`values-ru`) или
  английский (fallback).

### Требования

- Android 8.0 (API 26) и выше.
- FlipperZero с прошивкой, поддерживающей RPC DataExchange, и установленным приложением
  `bc_scanner` (репозиторий `bc_scanner_emulate`), работающим в RPC-режиме.
- Целевое устройство, эмулирующее COM-сканер, подключено к FlipperZero по USB.

### Примечания

- Значение передаётся «как есть», без суффикса CR/LF.
- APK подписан release-ключом.
- Совместимо с Flipper-приложением `bc_scanner`.
