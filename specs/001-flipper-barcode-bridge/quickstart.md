# Quickstart: Проверка фичи «Мост FlipperZero → сканер штрихкодов»

**Feature**: `001-flipper-barcode-bridge` | **Date**: 2026-10-10

Руководство по сквозной проверке. Не содержит реализации — только шаги, команды и ожидаемые
результаты. Детали интерфейсов — в `contracts/`, модель — в `data-model.md`.

## Предварительные требования

- FlipperZero с прошивкой, поддерживающей RPC DataExchange.
- Flipper-приложение `bc_scanner` (репозиторий `bc_scanner_emulate`, доработанное, с RPC-режимом) собрано и установлено.
- Android-устройство (`minSdk` 26) с разрешениями Bluetooth и камеры.
- FlipperZero сопряжён с телефоном; Bluetooth включён.
- Целевое устройство (эмуляция COM-сканнера) подключено к FlipperZero по USB и открыло COM-порт.

## Сборка и установка

### Flipper-приложение (соседний репозиторий)

```bash
# сборка (из каталога приложения bc_scanner_emulate)

ufbt

# сборка и запуск на подключённом FlipperZero

ufbt launch
```

### Android-приложение (текущий репозиторий)

```bash
# сборка debug-варианта
./gradlew assembleDebug
# установка на подключённое устройство
./gradlew installDebug
```

## Автоматические проверки (TDD)

```bash
# unit-тесты: кодек RPC-фреймов, корреляция команд, use-cases, ViewModel
./gradlew testDebugUnitTest
```

Ожидаемо: тесты зелёные; покрыты как минимум:
- кодирование/декодирование кадра `varint + PB_Main`;
- корреляция ответа по `command_id` и таймаут → `Error`;
- выбор кода с максимальной `confidence` при нескольких в кадре;
- переходы `ConnectionState` и `DeliveryStatus`.

## Сценарий 1 — Статус подключения (US1, P1)

1. Включить FlipperZero, убедиться, что Bluetooth активен.
2. Запустить Android-приложение.
3. **Ожидаемо**: статус «Подключено» в течение 5 с (SC-002), доступна кнопка «Сканировать».
4. Выключить FlipperZero.
5. **Ожидаемо**: статус меняется на «Не подключено» без падения приложения.

## Сценарий 2 — Сканирование и доставка (US2, P1)

1. При подключённом FlipperZero нажать «Сканировать».
2. Навести камеру на известный штрихкод или QR-код.
3. **Ожидаемо**: значение распознано и доставлено; на главном экране отображается значение и статус
   «отправлено на FlipperZero» (подтверждено ack).
4. **Ожидаемо**: целевое устройство получило значение через COM-порт (без суффикса).
5. Повторить для следующего кода (повторное нажатие «Сканировать»).

## Сценарий 3 — Несколько кодов в кадре (FR-016)

1. Открыть сканер и поместить в кадр два разных кода.
2. **Ожидаемо**: отправлен один код — наиболее уверенно распознанный; UI не «зависает».

## Сценарий 4 — Ошибки и восстановление (US3, FR-009, FR-014, FR-015)

1. Начать сканирование и в этот момент выключить FlipperZero.
2. **Ожидаемо**: показан статус «ошибка отправки» (таймаут ack или обрыв), приложение не зависает.
3. Включить FlipperZero, дождаться статуса «Подключено», повторить сканирование.
4. **Ожидаемо**: повторная отправка успешна без перезапуска приложения (SC-005).
5. Открыть на FlipperZero другое приложение (не `bc_scanner`), затем инициировать сканирование.
   **Ожидаемо**: ошибка «Flipper не готов», доступен повтор.

## Сценарий 5 — Разрешения (FR-004)

1. Отозвать разрешение камеры (или Bluetooth) в настройках ОС.
2. Запустить приложение и нажать «Сканировать».
3. **Ожидаемо**: запрос разрешения в момент использования; при отказе — понятное сообщение, без
   аварийного завершения (SC-006).

## Сценарий 6 — Язык интерфейса (FR-018)

1. Установить системный язык Android = русский, запустить приложение.
   **Ожидаемо**: интерфейс на русском.
2. Сменить системный язык на любой не-русский, перезапустить приложение.
   **Ожидаемо**: интерфейс на английском.

## Критерии успеха (связь)

| Критерий | Как проверить |
|----------|---------------|
| SC-001 | Полный путь «подключён → сканирование → отправка» < 60 с |
| SC-002 | Статус обновляется ≤ 5 с (сценарий 1) |
| SC-003 | ≥ 95% сканирований доставлены с первой попытки |
| SC-004 | Распознавание и отправка ≤ 3 с после наведения камеры |
| SC-005 | Восстановление после обрыва без перезапуска (сценарий 4) |
| SC-006 | Нет аварийных завершений при отсутствии Flipper/разрешений (сценарий 5) |
