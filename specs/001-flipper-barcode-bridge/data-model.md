# Phase 1 Data Model: Мост «FlipperZero → сканер штрихкодов» через BLE

**Feature**: `001-flipper-barcode-bridge` | **Date**: 2026-10-10

Модель данных описывает предметную область Android-приложения. Платформенные типы (BLE, protobuf)
за абстракциями не протекают в домен. Данные хранятся в памяти (сессия), кроме MAC-адреса
устройства.

## Сущности

### FlipperDevice (устройство)

Устройство FlipperZero, с которым устанавливается соединение.

| Поле | Тип | Описание | Правила |
|------|-----|----------|---------|
| `address` | String (MAC) | Уникальный идентификатор BLE-устройства | Обязателен; уникален; используется для авто-подключения (FR-011) |
| `name` | String? | Отображаемое имя (например, «Flipper …») | Необязательно; только для UI |

**Уникальность**: ключ — `address`.

**Хранение**: последний успешно использованный `address` сохраняется в DataStore; список устройств
не ведётся.

### ConnectionState (состояние соединения)

Состояние связи приложения с FlipperZero; отображается на главном экране (FR-002).

| Значение | Смысл | Переходы |
|----------|-------|----------|
| `Disconnected` | Связи нет | → `Connecting` (старт подключения) |
| `Connecting` | Идёт подключение/установка сессии | → `Connected` (успех) / → `Error` (сбой) / → `Disconnected` (отмена) |
| `Connected` | GATT подключён, RPC-сессия доступна | → `Disconnected` (обрыв) |
| `Error(reason)` | Ошибка подключения/сессии | → `Connecting` (повтор) / → `Disconnected` |

**Правила**: кнопка «Сканировать» доступна только в `Connected` (FR-003). Обновление состояния —
автоматически при GAP-событиях (FR-002).

### ScannedCode (отсканированный код)

Значение, полученное с камеры.

| Поле | Тип | Описание | Правила |
|------|-----|----------|---------|
| `value` | ByteArray / String | Значение кода (сырые байты) | Непустое; длина в допустимых пределах протокола |
| `format` | BarcodeFormat | Формат кода | Любой из поддерживаемых движком (FR-006) |
| `confidence` | Float? | Уверенность распознавания | Используется для выбора при нескольких кодах (FR-016) |
| `scannedAt` | Instant | Момент распознавания | Для отображения/диагностики |

**Правила**: при нескольких кодах в кадре выбирается с максимальной `confidence` (FR-016);
пустое/некорректное значение не отправляется (US2 п.6).

### DeliveryStatus (статус доставки)

Статус передачи значения на FlipperZero (FR-013).

| Значение | Смысл |
|----------|-------|
| `Pending` | Значение отправлено в BLE, ожидается ack |
| `Delivered` | Получен ack (`CommandStatus OK`) |
| `Error(reason)` | Таймаут ack / ошибка записи / ошибка Flipper / обрыв связи |

**Правила**: `Delivered` — только при получении ack (FR-015). При `Error` пользователь может
повторить (FR-010, FR-014).

### LastSentCode (последний отправленный код)

Хранится в памяти сессии для отображения на главном экране после отправки (FR-012, FR-017).

| Поле | Тип | Описание |
|------|-----|----------|
| `code` | ScannedCode | Последнее отправленное значение |
| `status` | DeliveryStatus | Итоговый статус последней отправки |

**Правила**: хранится только одно значение; история не ведётся; не передаётся во внешние сервисы.

### AppSettings (настройки)

| Поле | Тип | Описание | Правила |
|------|-----|----------|---------|
| `lastDeviceAddress` | String? | MAC последнего устройства | Для авто-подключения (FR-011) |

Язык интерфейса определяется локалью ОС (русский → русский, иначе английский) и не хранится (FR-018).

## Состояния и переходы

### Соединение

```text
Disconnected ──connect()──▶ Connecting ──ok──▶ Connected
      ▲                          │                 │
      │                       fail│              drop│
      │                          ▼                 ▼
      └──────── retry ───────  Error ─────────▶ Disconnected
```

### Доставка одного кода

```text
[Camera] ──scan──▶ ScannedCode ──send()──▶ Pending ──ack──▶ Delivered
                                                 │
                                            timeout/error
                                                 ▼
                                             Error ──retry──▶ Pending
```

## Отношения

- `FlipperDevice` 1 ── * `ConnectionState` (во времени; активное состояние одно).
- `ScannedCode` 1 ── 1 `DeliveryStatus`.
- `LastSentCode` ссылается на последний `ScannedCode` и его `DeliveryStatus`.

## Валидация (связь с требованиями)

| Правило | Требование |
|---------|-----------|
| Кнопка «Сканировать» только при `Connected` | FR-003 |
| Успех доставки только при ack | FR-015, FR-013 |
| Выбор одного кода при нескольких в кадре | FR-016 |
| Хранение только последнего отправленного кода | FR-017 |
| Хранение MAC для авто-подключения | FR-011 |
| Язык интерфейса по локали ОС | FR-018 |
